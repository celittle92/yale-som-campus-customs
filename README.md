# Yale SOM — AI Foundations, Homework 4

Campus Customs: a storefront for a shop selling officially licensed Yale apparel, with a
shopping assistant that answers price and stock questions from the shop's own database.

**Everything is in [`hw4/`](hw4/).** Start with:

- [`hw4/README.md`](hw4/README.md) — how to run the front end and the backend
- [`hw4/output/harness.md`](hw4/output/harness.md) — how the system works
- [`hw4/AI_prompts.md`](hw4/AI_prompts.md) — the prompt log for the assignment
- [`hw4/output/app_check.html`](hw4/output/app_check.html) — screenshots of it running

The supplied database and product photos are deliberately **not** in this repository; the
assignment forbids committing them. [`hw4/README.md`](hw4/README.md) explains where to put
your own copy.
